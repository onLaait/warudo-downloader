# Warudo Downloader

This mod allows you to download worlds from any multiplayer server.

## Features

* **World download command**
* **Minimap** that visualizes downloaded chunks

## What it downloads

* Blocks
* Entities (Players are saved as Mannequins)
* Maps
* Some world data (Time, Weather, World Border)
* Data packs (Dimension Type, Biomes, Timelines)
* Resource packs
* Server icon

## How to use

* To start downloading, use the command: `/downloadworld start [distance]`
* To stop downloading, use the command: `/downloadworld stop` or just leave the world.
* Downloaded worlds are saved directly to your singleplayer world list (in the `.minecraft/saves` folder).
